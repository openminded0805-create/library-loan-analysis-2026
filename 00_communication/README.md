# 프로젝트 소통 및 폴더 가이드 (도서관 장서대출 데이터 기반 수서 최적화)

이 폴더는 사용자와 AI가 파일 기반으로 명확하게 소통하고 자료를 공유하기 위한 공간입니다.

## 📁 폴더별 파일 넣는 위치 안내

1. **`02_data/raw/`** (데이터 넣는 곳)
   - 보유하고 계신 **도서관 장서 데이터, 대출 이력 데이터 (CSV, XLSX, TXT 등)** 파일이나 폴더를 여기에 넣어주세요.

2. **`01_references/domain_papers/`** (내용/논리 레퍼런스)
   - 수서 최적화 관련 참고할 보고서, 논문, 발표자료(PDF, 워드, 텍스트, 이미지 등)나 인용하고 싶은 레퍼런스 목록을 넣어주세요.

3. **`01_references/design_samples/`** (디자인/슬라이드 레퍼런스)
   - 원하시는 HTML 슬라이드 분위기, 색상 테마, 레이아웃 캡처 이미지나 참고용 HTML/CSS 파일이 있다면 여기에 넣어주세요.

4. **`00_communication/`** (소통 및 기획 조율)
   - `slide_outline.md`: 슬라이드 목차와 핵심 메시지를 함께 다듬는 문서입니다. 직접 수정하셔도 되고 채팅으로 말씀해 주셔도 됩니다.

---
**💡 팁**: 분류하기 애매한 폴더나 파일이 있다면 **`데이터과제1` 최상위 폴더에 그냥 통째로 붙여넣기** 해주세요! 제가 알아서 내용물을 확인하고 알맞은 폴더로 정리하겠습니다.
