# 2026년 도서관 인기대출도서(TOP 200) 데이터 심층 분석 보고서

> **분석 범위**: 수서 최적화 제언을 배제하고, 순수하게 업로드된 **국립중앙도서관 2026년 인기대출도서 TOP 200 데이터(`인기대출도서_2026.csv`)의 현황, 구조적 패턴, 독자 세그먼트별·주제별·시계열별 특성**만을 객관적으로 해부한 분석 문서입니다.

## 1. 데이터 개요 및 기초 통계 (Dataset Overview)

* **데이터 출처**: 국립중앙도서관 (데이터 제공일: 2026-10-16)
* **집계 기간**: `2026-01-01 ~ 2026-10-15` (약 9.5개월간의 전국 도서관 대출 집계)
* **검색 조건**: 성별 전체 / 연령 전체 / 지역 전체 / 주제 전체 (상위 200위 도서)
* **총 도서 수**: **200권**
* **총 대출건수 합계**: **2,996,340건** (약 300만 건)
* **권당 대출건수 분포**:
  * **평균(Mean)**: **14,981.7건** (표준편차: 3,667.8건)
  * **중앙값(Median)**: **13,824.5건** (평균보다 낮음 → 최상위권 베스트셀러가 평균을 끌어올리는 **우편향(Right-skewed) 롱테일 분포**)
  * **최대(1위)**: **35,344건** — 한강 『소년이 온다』 (2014, 창비)
  * **최소(200위)**: **11,363건** — 에그박사 『에그박사 : Egg&bugs 7』 (2020, 미래엔)
  * **구간별 집중도**:
    * 상위 10위(5%) 도서 대출 비중: **8.97%** (268,945건)
    * 상위 20위(10%) 도서 대출 비중: **15.92%** (476,979건)
    * 상위 50위(25%) 도서 대출 비중: **34.23%** (1,025,650건)
